# Mitotic Stopwatch Fate analysis

Data integration pipeline, analytical code, and data visualisation for mitotic stopwatch live-cell imaging experiments described in:

> Soares-de-Oliveira, Okada, Kletter et al. (2026) Low kinetochore-microtubule occupancy leaves a mitotic memory by delaying checkpoint silencing.

> bioRxiv preprint: https://doi.org/10.64898/2026.01.26.701783

## Goal

The goal of this pipeline is to integrate cell family tracking, mitotic outcomes, and daughter cell fates from long-term microscopy assays, where mitosis is delayed by one means or another (e.g. monastrol treatment + washout).

## How to Use This Repository

### 1. Install dependencies

Download and install the relevant Python packages (e.g. using the Anaconda + conda management system):

| Package | Version |
|---|---|
| python | 3.12.7 |
| jupyter | 4.2.5 |
| pandas | 2.2.2 |
| numpy | 1.26.4 |
| altair | 5.4.1 |

Download and install the relevant ImageJ/Fiji software and plugins:

| Software | Version |
|---|---|
| Fiji | 2.16.0 |
| TrackMate | 8.1.6 |

### 2. Repository structure

The code is divided into:
- **Macros** — ImageJ macros
- **Notebooks** — Jupyter notebooks

Part of the analysis pipeline requires (semi-)manual user input via ImageJ/Fiji; the other part integrates all user-generated outputs, saves meta-statistics, and finalises data visualisation.

### 3. Pipeline steps

1. **Starting point**: TrackMate result tables (generated by manual or automated tracking of cells across generations).

2. **Parse lineages**: Run `01_Parse_Trackmate_Lineages.ipynb` to generate, per tracked video, a new `_lineages` dataframe as well as a global summary dataframe.

3. **Annotate mitotic onset**: Using the semi-automatic ImageJ macro `01_Annotate_Mitotic_Onset.ijm`, annotate the mitotic onset (i.e. nuclear envelope breakdown) for each splitting event (anaphase).

4. **Annotate errors and endpoints**: In ImageJ, annotate mitotic defects and segregation errors using `02_Annotate_MitoticErrors.ijm`, and annotate deaths or loss of daughters using `03_Annotate_Endpoints.ijm`.

5. **Integrate**: Run `02_Integrate_Onsets_Defects_Endpoints.ipynb` to merge lineage information with mitotic durations and mitotic error events.

6. **Visualise**: Run `03_Visualisation_Statistics.ipynb` to filter the data in various ways (e.g. selecting mother cell cohorts, or excluding divisions with errors) and visualise it using the `altair` Python library.

## Demo

To run the minimal example workflow:

1. Download the example input files from the folder `Example Data`.
2. Open the respective Jupyter notebooks in Jupyter.

### `01_Parse_Trackmate_Lineages_Example.ipynb`

**Inputs** — edges and spots generated by TrackMate (via "export" after successful tracking):
- `1_TrackMate_edges.csv`
- `1_TrackMate_spots.csv`
- `2_TrackMate_edges.csv`
- `2_TrackMate_spots.csv`

Define the locations of these tables in the input cell.

**Outputs**:
- `..._lineages.csv` — contains all track lineages and their relationships
- `..._downstream.csv` — contains all downstream cell IDs of a splitting event
- `MainDataFrame_Lineages_Example.csv` — combined dataframe
- `MetaStatistics_TrackingLineages_Example.csv` — a quality control table with relevant statistics of the lineages in the input file

### `02_Integrate_Onsets_Defects_Endpoints_Example.ipynb`

**Inputs** — already defined by default.

**Output**:
- `MainDataFrame_MitoticStopwatch_Example.csv` — final dataframe, containing the integrated lineage data with annotated mitotic errors and daughter cell fates

**Runtime**: The total run time of the demo on a normal computer should be less than 3 seconds.
